Tutorial · Construye tu propio dashboard con IA

Sigue estos tres pasos. El Excel es el insumo para que la LLM genere un artefacto como el de la demostración.

1Descarga el archivo Excel

Abre la carpeta compartida de Google Drive y descarga invernadero_datos.xlsx en tu equipo.

📥 Abrir carpeta de Excel

Comprueba que descargaste el archivo correcto antes de continuar.

2Ingresa a una LLM

Elige una herramienta de inteligencia artificial y adjunta el Excel descargado en el paso anterior.

Gemini ChatGPT Claude Perplexity Grok DeepSeek KIMI GLM 5

Estas opciones proceden de la sección «Apropiación» del material de referencia. La disponibilidad de carga de archivos puede variar entre servicios y planes.

3Pega el siguiente prompt

Con el Excel adjunto a la conversación, copia y envía esta instrucción a la LLM.

A partir del Excel que te comparto, analiza su estructura y genera un artefacto monolítico HTML, CSS y JavaScript vanilla, responsivo, que permita cargar archivos con la misma estructura. Incluye dashboard con textbox, select, checkbox, slider, botones, gráficos JavaScript interactivos, validación y resumen automático. Identifica visualmente cada componente UI.
