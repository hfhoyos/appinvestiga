Pegar el prompt

Copia esta instrucción en la LLM y solicita el archivo HTML.

Construye una artefacto HTML, CSS y JS vanilla. (A) ARTEFACTO: Página web responsiva llamada «Guadua Noble», una tienda virtual de productos derivados de la guadua. Entrega un único archivo HTML CSS y Js integrados, funcional y sin backend. Diseña tarjetas con fotografías, nombre, descripción, categoría y precio, además de un buscador, filtros y vista de detalle. (B) ALMACENAMIENTO: Usa localStorage para guardar, recuperar, actualizar y eliminar publicaciones. Los cambios deben persistir al recargar la página en el mismo navegador. Incluye un catálogo inicial de ejemplo, con datos ilustrativos claramente identificados. (C) TEMÁTICA: Organiza los productos en las categorías «Materiales de construcción», «Paneles», «Cercas», «Estructuras» y «Decoración». Permite incorporar las imágenes adjuntas y cambiar las fotografías de las publicaciones. (D) MODO ADMINISTRADOR: En la parte superior incluye un desplegable «Usuario / Administrador». Al seleccionar Administrador solicita la contraseña de demostración «1234». Si es correcta, permite agregar, editar y eliminar publicaciones, incluyendo imagen, nombre, descripción, categoría y precio. Usa formularios validados, confirmación de eliminación, botones Guardar/Cancelar y actualización inmediata del catálogo. Incluye opción de cerrar sesión y restablecer el catálogo de ejemplo. (E) MODO USUARIO: Acceso directo sin contraseña. Permite consultar, buscar y filtrar productos y abrir sus detalles. No muestra botones para agregar, editar ni eliminar publicaciones. (F) FUNCIONAMIENTO: Implementa navegación funcional, diseño adaptable a móvil, mensajes de confirmación, manejo de errores y compresión de imágenes para reducir el uso de localStorage. No uses backend. Aclara que la contraseña en HTML local es solo una simulación educativa, no seguridad real. Entrega el HTML completo, listo para guardar y abrir en un navegador.
