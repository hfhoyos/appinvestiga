02 · Prompt (Tutorial)

Para desarrollar este taller, primero descarga la base de conocimiento y después utiliza el prompt con una LLM.

  1. Descargar el RAG: abre la carpeta de Google Drive del Taller 4 y descarga el archivo rag.js.
  2. Preparar la carpeta: coloca rag.js en la misma carpeta donde guardarás index.html. Conserva exactamente el nombre rag.js.
  3. Generar el artefacto: copia el siguiente prompt en la LLM de tu elección y guarda el HTML generado como index.html. No necesitas subir rag.js a la conversación.
  4. Comprobar: abre index.html y verifica que aparezca «RAG disponible» antes de generar la secuencia didáctica y el mapa de procesos.
