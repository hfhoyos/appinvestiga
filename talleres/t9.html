ChatGPTGeminiClaude
Construye un artefacto monolítico HTML, CSS y JavaScript Vanilla, responsivo, llamado «Generador de imágenes con IA».

(A) INTERFAZ: Crea dos pestañas «Demostración» y «Prompt (Tutorial)». En la demostración incluye proveedor OpenAI/Gemini, modo simulación/real, campo API Key tipo password, descripción de imagen, selector de estilo y proporción, botones Generar, Limpiar, Nueva versión y Descargar. Muestra la imagen y estados de carga y error.

(B) GENERACIÓN: En modo real conecta con una API de generación de imágenes compatible. Para OpenAI utiliza el endpoint de imágenes y un modelo GPT Image compatible; para Gemini utiliza generateContent con un modelo de imagen compatible. Gestiona las diferencias de formato y respuesta de cada proveedor. Los modelos pueden cambiar: permite seleccionar su identificador desde la interfaz, con una opción personalizada y mensajes claros si el modelo no existe o no está habilitado.

(C) EXPERIENCIA: Construye el prompt final con la descripción, estilo y proporción. Permite nuevas versiones, previsualización y descarga. Muestra advertencias sobre consumo de tokens, costo y tiempo, sin inventar precios.

(D) SIMULACIÓN: Incluye un ejemplo visual local claramente identificado como simulación. No afirmes que fue generado por una API.

(E) SEGURIDAD: Nunca incluyas credenciales en el código, ejemplos o archivos. No guardes la clave en localStorage, sessionStorage ni cookies. Advierte que el navegador no protege la clave y que en producción se requiere backend intermediario. Nunca pidas pegar la clave en una conversación con una LLM.

Entrega el archivo HTML completo y funcional.

Actividad didáctica · La generación real depende del acceso a la API y sus condiciones.
