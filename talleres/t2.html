📚 Tutorial · Construye tu ficha interactiva desde Excel

Sigue los tres pasos para crear tu propio artefacto con ayuda de una LLM.

1

Descarga los archivos de Excel que aparecen en esta carpeta

Descarga las tres fichas de proyecto. Todas utilizan la misma plantilla.

📁 Abrir carpeta de archivos Excel

La carpeta se abrirá en una pestaña nueva.

2

Ingresar a una LLM

Selecciona la herramienta de IA que prefieras. Adjunta uno de los Excel descargados.

ChatGPT ↗ Gemini ↗ Claude ↗ Perplexity ↗ Grok ↗ DeepSeek ↗ KIMI ↗ GLM 5 ↗
3

Pegar el prompt

Copia y pega estas instrucciones en la LLM, en orden, con el Excel adjunto.

Prompt 1 · Comprender el Excel

Analiza el archivo Excel que te comparto. Identifica el nombre de la hoja, los campos de la ficha de proyecto y la ubicación exacta de cada dato. ¿Comprendes su estructura?

Prompt 2 · Generar el artefacto

A partir de la estructura del Excel que comprendiste, genera un artefacto monolítico HTML, CSS y JavaScript vanilla, responsivo, que permita cargar archivos Excel con esa misma plantilla, leer las celdas fijas y presentar todos los datos en una ficha visual. Incluye objetos UI, validación e impresión.

Demostración · Probar con las tres fichas

Esta página incluye un lector de demostración funcional. Carga uno de los tres archivos y comprueba que los valores se muestran sin cambiar el código. El procesamiento se realiza en tu navegador, sin enviar el archivo a un servidor.
