⚙️ Configuración

La clave solo permanece en memoria durante esta sesión. No se guarda ni se exporta.
Seguridad: ingresar una API Key en el navegador NO la protege frente a inspección de red ni scripts. Este modo directo es solo demostrativo. En una aplicación real usa un backend intermediario que conserve la clave como secreto. No publiques ni compartas tu clave.

🎯 Propósito pedagógico

El asistente está configurado para conversar sobre cultivo, variedades, tostión, molienda, extracción, métodos de preparación, bebidas y técnicas de barismo. Ante una pregunta ajena al café, debe redirigir respetuosamente la conversación.
La especialización mediante un prompt de sistema orienta el comportamiento, pero no constituye un filtro infalible. La simulación ofrece respuestas predefinidas, no generadas por IA.
